Test overview by install profile

What passes in an OVOS install, profile by profile. Each profile builds on the one before it: Default is what the OVOS installer puts on, Extra adds the installer's extra skills, and Klondike adds the curated entries of the Klondike profile. The rows are the store's own channel tests; nothing here is tested twice. Everything the installer puts on is tested, whatever its status in the store, so a gap here is a gap on real devices.

How to read this page
✓ loads Installs under the channel's own versions and loads in a test core (level 2). No golden utterances were measured, so it says nothing about whether sentences reach it.
✓ 14/14 golden Level 3: 14 of its 14 own golden utterances reached it with the installer's default skills loaded. Below 80% it shows as ✓ loads · 9/14 golden.
✗ doesn't load Installs but fails to load (level 1), or doesn't install at all (level 0). The entry's detail page shows why.
· untested In the store, but no result on this channel yet (e.g. just added to the tests).
– needs device Not a failure: it needs a real device, a key or an account, or the channel cannot run this kind of package.
∅ not in the store The installer puts it on, but the store has no entry for it, so it is not tested here.
archived The repo is archived on GitHub, but the installer still installs it.
with Klondike: 13/14 The same golden utterances, routed with the whole Klondike profile loaded (en-US): does it still get its sentences on a well-equipped install?
⛏ Gold A skill: level 3, and at least 80% still reach it with the Klondike profile loaded. A pipeline plugin: in the Klondike test it took sentences for the skills they belong to, and took none from other skills.
routing: reaches 5 · takes 0 Pipeline plugins: in the Klondike test, how many sentences it took and handed to the skill they belong to, and how many it took from the skill they belong to (hover for which). Measured only where OVOS says which plugin matched a sentence (alpha today); elsewhere it reads not measurable here.
⚠ the installer's pipeline is incomplete A stage of the installer's own pipeline did not load on this channel, so level 3 there ran without it, as a device on that channel would.
